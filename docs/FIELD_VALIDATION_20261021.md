# EV 텔레메트리 실전 검증 결과

**상태: 실전 검증 완료 — 프로젝트 담당자 확인**

## 주요 성과

- **토크벡터링 보정 기여:** EV 텔레메트리를 활용해 토크벡터링 보정에 기여했다.
- **대회장 실시간 수신:** 대회 현장에서 실시간 차량 값을 수신하고 확인했다.
- **주행 중 BMS 모니터링:** 테스트 주행 중 BMS 값을 실시간으로 확인했다.
- **배터리 온도 이상 발견과 대응:** 배터리 온도가 비정상적으로 상승하는 현상을 포착했고, 피트인하여 차량을 점검할 수 있는 기회를 확보했다.

## 현장 사례

테스트 주행 중 피트에서 BMS 값을 실시간으로 확인하던 과정에서 배터리 온도의 비정상적인 상승을 발견했다.
이 정보를 바탕으로 피트인하여 점검할 수 있었다.
실시간 차량 데이터가 토크벡터링 보정뿐 아니라 주행 중 차량 상태 파악과 현장 대응 판단에도 활용된 사례다.

**관찰·대응 흐름:** 테스트 주행 → 실시간 BMS 확인 → 배터리 온도 이상 상승 포착 → 피트인 → 점검 기회 확보.

## 확인 근거

프로젝트 담당자가 EV 텔레메트리와 토크벡터링의 실전 검증 완료를 직접 확인했다.
이 문서는 2026-10-21에 해당 현장 결과를 기록한 것이며, 실제 대회·주행 일자를 뜻하지 않는다.
정량 성능 수치, 온도 최고값, 이상 원인 및 점검 후 조치 결과는 이번 확인에 포함되지 않았다.
현장 운용 성과와 이번 소스 통합의 자동 테스트 결과는 구분한다.

## 소스 업로드 검증 — 2026-10-21

- 원격 `b57ac9d`를 기준으로 로컬의 배터리 잔여 주행시간·전비, 차속 환산 설정, 온보드 HUD, 드라이버 소통, 피트 조정 및 ESP 통신 변경을 반영했다.
- `python -m unittest discover -s tests -v`: **134개 통과**.
- Windows에서 접근 거부 응답 전에 읽지 않은 POST 본문으로 연결이 종료되는 문제를 수정했다. 기존 본문 크기 제한을 적용해 읽고, 인증·로컬 접근 조건을 확인한 뒤 JSON 파싱·처리한다.
- 공개 설정 예제의 Wi-Fi 값은 자리표시자로 정리하고 LR 공용 설정 예제를 추가했다. 개인 `config.h`, LR 키 설정, 주행 DB와 빌드 산출물은 업로드 대상에서 제외했다.
- 원본 작업 폴더를 유지한 별도 작업 공간에서 검증했다. 이번 업로드는 실제 차량 재플래시나 운영 서버 재배포를 수행하지 않는다.
